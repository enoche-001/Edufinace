Add or remove an admin

  1. The person signs in once at login.html so their account exists.
  2. Copy their UID from Firebase Console > Authentication > Users.
  3. Open Firestore > admins and add a document using that UID as the Document ID, with a field email (string).
  4. To remove an admin, delete that document.

Admin rights can only be changed from the Firebase Console. Nobody can grant themselves admin access from the app.
